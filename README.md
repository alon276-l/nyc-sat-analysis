# NYC SAT Performance Analysis

Mini data analysis project using pandas.

## Objective
Analyze SAT performance across NYC public schools.

## Tech Stack
- Python
- pandas
- Jupyter Notebook

## Analysis Questions
- Which schools have the best math scores?
- Which are the top 10 schools by total SAT score?
- Which borough has the highest SAT score variability?

## Dataset
Datacamp educational dataset: `schools.csv`

## Key Skills Demonstrated
- Data filtering
- Aggregations with groupby
- Sorting
- Creating new columns
- Descriptive statistics
